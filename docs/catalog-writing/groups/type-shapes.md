# Typeface shapes / 서체 형태 / 書体の形

Group ID: `type-shapes` · Checked: 2026-09-21 · Writing designs, not article bodies.

## Shared case and comparison contract

Compare the same text: Field notes 2026 / 기록 2026 / 記録 2026, plus a magnified Latin H, n and a. Keep nominal size and text constant; describe fallback coverage separately.

**Comparison axes, fixed order:** stroke endings; construction; handwritten reference; script coverage; intended text role; independence from width.

**Boundary:** Shape groups are broad conventions, not individual font products. Latin serif/sans/script terms do not map perfectly to all Korean/Japanese styles. Script here means handwriting-like type, not a programming language or Unicode script.

**Visual family:** Annotated glyph silhouettes and identical multilingual specimen lines; no font-product ranking or fabricated readability score.

**Core terms (EN / KO / JA):** Glyph / 글리프 / グリフ; Stroke / 획 / ストローク; Fallback / 대체 글꼴 / フォールバック.
