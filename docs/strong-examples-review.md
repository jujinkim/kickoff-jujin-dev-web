# Distinguishing examples and image delivery — 2026-09-27

User follow-up: every field needs deliberately strong examples, and images must transfer far less data. This review covers all 73 active demos. Stable identities, prompts, AI guidance and reference routes remain unchanged.

## Review rule

A title or color swap cannot establish the difference. Amplify material, topology, ownership, timing or numerical consequence while retaining correctness, keyboard/reflow support and fallbacks. Existing situations remain aligned in English/Korean/Japanese. Glassmorphism can animate; Liquid Glass is a named Apple material, not merely a stronger blur. The web lens is an explicitly limited illustration.
