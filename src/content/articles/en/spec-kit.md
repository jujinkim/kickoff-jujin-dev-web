## Why: the goal or problem

A concert booking service lets fans reserve seats and join a waitlist. Separate booking and notification changes must follow one release rule. Its developers need traceable agreement; an isolated label correction would need less structure.

## How: work toward a solution

Specify when a released seat goes to the waitlist, plan the boundary, and link implementation tasks to that rule. Check the code against the artifacts and resolve gaps. Reuse confirmed answers.

## What: the concept

Spec Kit provides agent workflows, templates, and setup tools for specification-driven development. It also offers optional repair and idea-assessment processes. Choose by coordination and risk; size alone does not justify installation.
