## 왜 필요한가

공개 자전거 경로 도구가 조용한 길을 찾도록 돕습니다. 자원봉사자가 자유 라이선스 코드를 개선합니다. 자체 서버 관리보다 비영리 자유 소프트웨어 공동체에 협업 운영을 맡기고 싶습니다.

## 어떻게 해결하는가

조건에 맞는 프로젝트를 Codeberg에 공개합니다. 기여자가 fork에서 경로 표시 수정을 제안하고 PR을 엽니다. 프로젝트 관리자는 검토·병합하고 Codeberg 운영자는 호스팅을 관리합니다.

## 무엇이라 부르는가

Codeberg는 Git 기반 Forgejo를 사용하는 비영리 공동체 서비스입니다. Gitea는 직접 운영할 수 있는 소프트웨어입니다. 프로젝트 허용 조건과 자원 정책을 확인해야 하며 공동체 호스팅이 무제한 자원을 뜻하지는 않습니다.
