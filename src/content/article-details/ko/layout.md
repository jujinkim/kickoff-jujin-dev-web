## 선택·비교

순차 읽기에는 한 흐름, 지속 보조에는 사이드바, 동시 참고에는 여러 영역을 씁니다. 반복 텍스트는 행, 시각 자료 비교는 균등 카드, 다른 이미지 높이는 메이슨리에 맞습니다. 페이지 영역과 CSS 다단 텍스트 흐름은 다릅니다.

## 응용 사례

카탈로그 스케치는 탐색·필터·결과·상세에 이름을 붙입니다. 좁은 화면은 유용한 소스 순서대로 영역을 쌓습니다. 빈 결과에서도 필터와 복구 경로를 유지합니다. 각 영역은 주요 행동을 다투기보다 항목 찾기를 돕습니다.

## 구현 참고·주의점

경계를 정하기 전에 긴 문구·펼친 내용·키보드 순서·확대를 시험합니다. 실제 모달은 포커스 제한·Escape·포커스 복귀가 필요하며 그린 대화창은 도식일 뿐입니다. 조작 카드에 CSS 다단을 적용하려면 시각·키보드 순서를 확인합니다.
