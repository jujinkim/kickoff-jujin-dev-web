## Selection & comparison

Assess whether existing instructions, acceptance criteria, and checks already cover the work. Project size is not a cutoff: a large maintained codebase can need no extra setup, while a small permission change may need a detailed specification. This is an editorial fit recommendation, not evidence that fewer tools improve model results. Compare Spec Kit for requirement tracking, Superpowers for repeatable execution skills, and OpenSpec for reviewed changes.

## Applications

The club confirms that the next meeting is in the library, while its date and registration link stay unchanged. The external agent reads repository instructions, changes the venue label, runs the established checks, and reviews the rendered page. A passed check is reported as a result; an unavailable browser is reported as unverified. Existing records remain the source of truth.

## Implementation & cautions

No installation is needed for this option. Reuse the external agent and project setup already available. Do not uninstall useful skills or suppress existing rules to achieve “no extra skills.” Record adopted criteria and consequential decisions in existing documents. If the task grows into shared scheduling rules, reassess workflow needs rather than adding every suggested package. A chat-only assistant can provide a plan and manual checks but cannot claim to have changed or tested files.
