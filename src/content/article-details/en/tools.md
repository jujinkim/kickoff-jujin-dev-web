## Selection & comparison

Compare alternatives that address the same required outcome. A language is not a substitute for an engine; a library may run inside a framework. Prefer the smallest stack that demonstrates publishing, interaction and maintenance needs. An engine fits an interactive world when its runtime systems earn their cost.

## Applications

The catalog map combines TypeScript rules, an optional React filter and Astro pages. The separate Godot branch combines scenes and runtime systems with a scripting language. It shows coexistence and different outputs, not four mutually exclusive product choices.

## Implementation & cautions

Verify exports, license, supported platforms and an awkward requirement in a complete small slice. Tool roles overlap, and product versions change. The static diagram executes no engine or framework and cannot establish performance or deployment support for a proposed stack.
