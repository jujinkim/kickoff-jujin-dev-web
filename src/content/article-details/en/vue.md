## Selection & comparison

Choose Vue when HTML-like templates and colocated component logic fit the team. React favors a JavaScript-centered composition model; Svelte emphasizes compilation. All can manage shared state, so a synchronized counter alone does not distinguish them.

## Applications

The reading shelf saves a library book and a garden article. Each card owns its label while a shared record set supplies the total. A repeat save leaves the total unchanged under this example’s identity rule.

## Implementation & cautions

Decide where state is owned before connecting templates. Derive counts from records rather than updating separate counters. This page resets all model state on reload; a real cross-device shelf needs authenticated persistence and failure handling outside the component.
