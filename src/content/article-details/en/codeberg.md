## Selection & comparison

The deciding priority is a nonprofit free-software community operating the service. GitHub may fit an existing contributor network; Gitea fits owning your instance. Codeberg uses Forgejo, a separate software project. Compare review workflow, integrations, service policies and migration needs; nonprofit operation does not guarantee every requested feature.

## Applications

Cycling volunteers collaborate on the route tool’s code through forks and PRs. Project maintainers decide which changes to merge; service operators keep the collaboration platform running. The example concerns code, not uploading private ride traces. Its public license and purpose must fit the service’s rules.

## Implementation & cautions

Read current eligibility, private-content and resource policies before creating a project. Check automation and storage suitability for real workloads rather than assuming unlimited free capacity. Retain a recovery and migration plan: Git history, issue discussions and service configuration are different records. Test the destination’s import support if moving.
